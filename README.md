# PT. Mitra Utama Cemerlang — Landing Page

Modern B2B corporate landing page built with Next.js, TypeScript and Tailwind CSS.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Build

```bash
npm run build
npm start
```

## Deployment

Designed for Netlify. Use the standard Next.js build configuration.

## Notes

- Portfolio images and the MUC logo are extracted from the provided company profile PDF.
- The supplied company data includes an office telephone number but no official WhatsApp/sales number, so the primary CTA currently scrolls to the contact section. Replace it with the official WhatsApp URL when that number is confirmed.
- Portfolio entries intentionally use generic labels until project/client details are supplied.
